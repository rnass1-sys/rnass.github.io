Assignment 9

Activity 1: HTML Tutorials and Basic Web Page Structure

The HTML Tutorials activity introduced me to Hypertext Markup Language (HTML) and how it structures web pages. I learned that HTML uses elements and tags to organize information, including headings, paragraphs, images, and hyperlinks. I also learned the purpose of essential elements such as DOCTYPE, html, head, title, and body. These elements help browsers interpret and display website content correctly. Understanding HTML structure will benefit me in future coursework by allowing me to create organized web pages. I can also apply this knowledge professionally when developing websites, presenting information online, or maintaining digital content.

Activity 2: Creating a Simple Web Page

The Creating a Simple Web Page activity helped me understand how different HTML elements work together to produce a functional website. I learned how headings organize information, paragraphs improve readability, and hyperlinks connect pages and online resources. I also learned that images can make websites more engaging when they support the content. One important concept was understanding how file organization affects website navigation. Incorrect file paths can prevent hyperlinks and images from displaying properly. I can apply these skills to future school projects by creating websites that are easy to navigate and understand. Professionally, these concepts can help me organize digital information and communicate effectively with different audiences.

Activity 3: HTML Validation

The HTML Validation activity taught me why checking website code for errors is important. I learned that the World Wide Web Consortium (W3C) provides validation tools to identify problems with HTML structure and markup. These errors may include missing elements, incorrect nesting, or improperly formatted code. I also learned that a website rendering correctly in one browser doesn't guarantee its HTML complies with web standards. Validation helps improve code quality, consistency, and compatibility across browsers. I can apply this knowledge by reviewing my work before submitting assignments or publishing websites. In a professional environment, validating HTML can help reduce technical problems and improve the reliability of online information.

Activity 4: Visual Studio Code and Git Version Control

The Visual Studio Code and Git activity introduced me to tools used for developing websites and managing revisions. I learned that Visual Studio Code provides an organized environment for editing HTML through features such as syntax highlighting, file management, and integrated source control. Git lets developers track changes, maintain project history, and sync files with online repositories like GitHub. I also learned the difference between saving changes locally and publishing them to an online repository. These concepts are valuable because they support organization, accuracy, and collaboration. I can apply these skills to future coursework by managing assignments more efficiently and maintaining updated versions of my projects. Professionally, version control can help me collaborate with others, document changes, and maintain accurate digital resources.
