Assignment 10

Activity 1: CSS Tutorials

The CSS Tutorials activity introduced me to Cascading Style Sheets (CSS) and how they control the appearance and layout of webpages. I learned how CSS works with HTML to format elements such as headings, paragraphs, backgrounds, colors, and fonts. I also learned how selectors, properties, and values work together to apply specific styles to webpage elements. Understanding the relationship between HTML and CSS helped me see how separating content from presentation makes websites easier to organize and maintain. I can apply these concepts in future web design projects by creating visually appealing, consistent, and organized webpages.

Activity 2: Create and Use Inline CSS

The Create and Use Inline CSS activity helped me understand how to apply styling directly to individual HTML elements. I learned that inline CSS uses the style attribute to change specific formatting properties, including text color, background color, font size, font family, and text alignment. This method is useful when an individual element requires a unique appearance. However, I also learned that inline CSS can become repetitive when multiple elements require the same formatting. I can apply this technique when developing webpages that need occasional styling adjustments or when testing different design choices.

Activity 3: Create and Use Internal CSS

The Create and Use Internal CSS activity introduced me to placing CSS rules in the style element in the HTML document’s head. I learned that internal CSS allows multiple elements on a single webpage to share consistent formatting without repeating individual style attributes. Using selectors makes it easy to apply consistent styling—such as colors, fonts, and text alignment—across multiple elements. This approach also keeps the HTML content more organized. I can apply internal CSS when developing individual webpages that require consistent formatting, especially when experimenting with different layouts and design ideas.

Activity 4: Create and Use External CSS

The Create and Use External CSS activity helped me understand how to connect a separate CSS file to an HTML document. I learned that external style sheets allow multiple webpages to share the same design rules, making website maintenance more efficient. I also became familiar with layout properties such as width, margin, padding, borders, and float, which help control the spacing and positioning of webpage elements. Additionally, I learned the importance of validating CSS to identify errors and improve compatibility. I can apply external CSS to future websites by maintaining consistent designs across multiple pages, improving organization, and creating responsive layouts for different devices. Overall, these activities strengthened my understanding of how CSS contributes to webpage design and development. I can use these skills in future coursework and professional projects to create accessible, organized, and visually consistent websites.
