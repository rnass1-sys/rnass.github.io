What I Learned

While completing this assignment, I learned how JavaScript can be used with HTML to make webpages more interactive. I learned how to display text using document.getElementById() and innerHTML, and how to use the Date() function to show the current date and time. I also learned how to use the HTML canvas element with JavaScript to draw text and shapes. I can apply these skills to my own websites by displaying information, adding interactive features, and creating simple graphics.
