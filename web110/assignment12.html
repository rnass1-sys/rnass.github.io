What I Learned

While completing this assignment, I learned how JavaScript works with HTML to make webpages more interactive and dynamic. I also learned how to use the HTML canvas element with JavaScript to display text and draw basic shapes. I can apply these skills to my own websites by displaying updated information, improving user interaction, and adding simple graphics to make webpages more engaging and functional.
