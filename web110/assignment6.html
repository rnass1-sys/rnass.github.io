Activity 1: Internet Services – Topic: Internet Communication Services

Through the Internet Services activity, I learned how different online services support communication and data exchange across networks. These services include tools for transferring files, sending messages, and enabling collaboration between users in different locations. One key concept I learned is that the Internet supports both text and binary file transmission through various systems, allowing information to move efficiently between devices. This activity showed that modern communication extends far beyond basic email and messaging. Instead, it relies on an interconnected ecosystem of behind-the-scenes services working together seamlessly. In my current and future environment, especially in web design and interactive media, I can apply this knowledge by choosing appropriate communication tools for sharing files, collaborating with teams, and managing digital content effectively.

Activity 2: VoIP / Messaging – Topic: Voice over Internet Protocol and Digital Communication

In the VoIP and messaging activity, I learned how Voice over Internet Protocol (VoIP) allows voice and multimedia communication over the Internet instead of traditional phone systems. VoIP works by converting voice into digital data packets transmitted over IP networks, making communication more flexible and cost-effective. I also learned how messaging platforms combine texting, video calls, and file sharing into one system, reflecting the idea of unified communications. This activity showed me how modern communication tools bring multiple functions together in a single platform. I will apply these insights to my future career by using video conferencing and messaging platforms to collaborate seamlessly with remote clients and team members. This is particularly vital in web development projects, where clear and consistent communication ensures project success.

Activity 3: Screen Sharing / Remote Desktop – Topic: Remote Access Technology

The Screen Sharing and Remote Desktop activity taught me how remote desktop software allows users to access and control another computer from a different location. This process works by streaming the desktop interface over a network, allowing users to view and interact with the host system remotely. I learned that this technology is useful for troubleshooting, collaboration, and accessing files without being physically present at the device. This concept is especially important in today’s digital environment where remote work is common. In my future environment, I can use remote desktop tools to assist others with technical issues, collaborate on design projects, or access my work from different devices, making my workflow more flexible and efficient.

Activity 4: FTP – Topic: File Transfer Protocol and Data Sharing

From the FTP activity, I learned that File Transfer Protocol (FTP) is the industry-standard method for transferring data between a client and a server across a network. FTP operates using a client-server model and allows users to upload, download, and manage files on remote systems. I also learned about secure variations like FTPS and SFTP, which protect data during transmission. This activity emphasized the importance of secure and reliable file sharing, especially when working with large files or sensitive information. In my current and future environment, I can apply this knowledge when uploading website files, managing servers, or sharing project assets, ensuring that my work is both accessible and secure.
