Assignment 13 - Databases

Single-Table SELECT Statements

The SELECT statement retrieves information from a database table. These examples use the Customers table to retrieve all columns, selected fields, filtered records, sorted results, and grouped counts.

  • Select all customers: SELECT * FROM CUSTOMERS;
  • Select only the customer ID and customer name: SELECT CustomerID, CustomerName FROM CUSTOMERS;
  • Select customer name, address, city, and postal code for customers in the United Kingdom: SELECT CustomerName, Address, City, PostalCode FROM CUSTOMERS WHERE Country = 'UK';
  • Select contact name and customer name, sorted alphabetically by contact name: SELECT ContactName, CustomerName FROM CUSTOMERS ORDER BY ContactName;
  • Count the total number of customers: SELECT COUNT(*) FROM CUSTOMERS;
  • Count the number of customers from each country: SELECT Country, COUNT(*) FROM CUSTOMERS GROUP BY Country;
  • Count customers by country, sorting by the count from highest to lowest and then by country alphabetically: SELECT Country, COUNT(*) AS TotalCustomers FROM CUSTOMERS GROUP BY Country ORDER BY TotalCustomers DESC, Country ASC;
  • Show countries with more than 10 customers, sorted by count and country: SELECT Country, COUNT(*) AS TotalCustomers FROM CUSTOMERS GROUP BY Country HAVING COUNT(*) > 10 ORDER BY TotalCustomers DESC, Country ASC;

Multiple-Table SELECT Statements

Multiple-table SELECT statements use INNER JOIN to combine information from two or more related database tables. These examples connect customers, orders, order details, and products to retrieve related information.

  • Display customer names, order IDs, and order dates: SELECT Customers.CustomerName, Orders.OrderID, Orders.OrderDate FROM Customers INNER JOIN Orders ON Customers.CustomerID = Orders.CustomerID;
  • Display customer names, order numbers, and order dates: SELECT Customers.CustomerName, Orders.OrderID AS [Order Number], Orders.OrderDate FROM Customers INNER JOIN Orders ON Customers.CustomerID = Orders.CustomerID;
  • Sort customer names and order numbers: SELECT Customers.CustomerName, Orders.OrderID AS [Order Number], Orders.OrderDate FROM Customers INNER JOIN Orders ON Customers.CustomerID = Orders.CustomerID ORDER BY Customers.CustomerName, Orders.OrderID;
  • Display order IDs, order dates, product names, and quantities: SELECT Orders.OrderID, Orders.OrderDate, Products.ProductName, OrderDetails.Quantity FROM ((Orders INNER JOIN OrderDetails ON Orders.OrderID = OrderDetails.OrderID) INNER JOIN Products ON OrderDetails.ProductID = Products.ProductID);
  • Calculate the extended price for each product ordered: SELECT Orders.OrderID, Orders.OrderDate, Products.ProductName, OrderDetails.Quantity, OrderDetails.Quantity * Products.Price AS ExtendedPrice FROM ((Orders INNER JOIN OrderDetails ON Orders.OrderID = OrderDetails.OrderID) INNER JOIN Products ON OrderDetails.ProductID = Products.ProductID);
  • Display order and extended price information for customer ID 2: SELECT Orders.OrderID, Orders.OrderDate, Products.ProductName, OrderDetails.Quantity, OrderDetails.Quantity * Products.Price AS ExtendedPrice FROM ((Orders INNER JOIN OrderDetails ON Orders.OrderID = OrderDetails.OrderID) INNER JOIN Products ON OrderDetails.ProductID = Products.ProductID) WHERE Orders.CustomerID = 2;
  • Display order and extended price information for Around the Horn: SELECT Orders.OrderID, Orders.OrderDate, Products.ProductName, OrderDetails.Quantity, OrderDetails.Quantity * Products.Price AS ExtendedPrice FROM (((Customers INNER JOIN Orders ON Customers.CustomerID = Orders.CustomerID) INNER JOIN OrderDetails ON Orders.OrderID = OrderDetails.OrderID) INNER JOIN Products ON OrderDetails.ProductID = Products.ProductID) WHERE Customers.CustomerName = 'Around the Horn';

INSERT, UPDATE, and DELETE Statements

INSERT adds a new record, UPDATE changes information in existing records, and DELETE removes records. The following statements complete the database modification activities.

  • Add a shipper with ID 4, name On Time Delivery, and phone number (503) 555 0123: INSERT INTO Shippers (ShipperID, ShipperName, Phone) VALUES (4, 'On Time Delivery', '(503) 555 0123);
  • Increase the price of every product by 1: UPDATE Products SET Price = Price + 1;
  • Reduce the price of every product by 1: UPDATE Products SET Price = Price - 1;
  • Change the new shipper's name to On-Time Delivery: UPDATE Shippers SET ShipperName = 'On-Time Delivery' WHERE ShipperID = 4;
  • Delete the new shipper: DELETE FROM Shippers WHERE ShipperID = 4;
