Activity 1: Internet Reference Models, Internet Protocols, and Domain Name System (DNS)

I learned how Internet reference models organize network communication into layers, with each layer responsible for specific tasks. I also learned that Internet protocols, such as TCP/IP, establish rules for transmitting data between devices. The Domain Name System (DNS) translates domain names into IP addresses, allowing users to access websites without memorizing numerical addresses. I can apply this knowledge to my web design studies by understanding how websites communicate over the Internet and how different networking technologies work together to deliver online content.

Activity 2: Review IP Address Settings for Your Local Network I learned how to review network settings to understand how a device connects to the Internet. IP configuration tools, such as ipconfig on Windows and ifconfig on macOS or Linux, display information about network connections and IP addresses. I also learned that DHCP can automatically assign IP addresses and that renewing a DHCP lease may help resolve certain connection problems. I can apply this knowledge to troubleshoot computer connectivity issues and optimize network configurations for future web design projects.

Activity 3: Verify Internet Connectivity I learned that several tools can help identify Internet connection problems. Checking physical connections and IP address settings can reveal basic network issues. The ping command tests connectivity between devices, while tracert and online traceroute tools show the route data takes to reach a destination. I also learned that nslookup checks how domain names are translated into IP addresses. I can apply these concepts to troubleshoot connection problems when websites fail to load and better understand how computers communicate across the Internet.

Activity 4: Research and Identify the Components Required to Set Up a Home Network I learned that a home network requires appropriate equipment, such as a modem, router, and devices that connect through wired or wireless connections. A router directs data between networks, while a wireless access point allows devices to connect through Wi-Fi. I also learned that network security is important for protecting connected devices and personal information. I can apply this knowledge when setting up a home network, choosing reliable equipment, and securing my connection for college assignments and future web design projects.

Overall, these activities helped me understand how network devices, protocols, and troubleshooting tools work together to support Internet communication. This knowledge will be useful as I continue learning about technology and developing my web design skills.
